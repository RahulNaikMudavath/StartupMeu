# CareerFlow

Please refer to the main repository [README.md](../../README.md) for full project documentation, architecture details, Kiro AI usage explanation, setup instructions, and test runner guides.

## Quick Commands

### Backend
```bash
cd backend
npm install
npm run dev     # Starts backend on http://localhost:5000
npm test        # Runs Jest integration & property tests
```

### Frontend
```bash
cd frontend
npm install
npm run dev        # Starts Vite dev server on http://localhost:5173
npm run test:unit  # Runs Vitest component & unit tests
npm run build      # Production bundle build
```
